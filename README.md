# PII_Checker

Tool to semi-automate detection of Personally Identifiable Information within data.
It reviews data for PII flags and searches variable labels in metadata for keywords for context-driven risks.
The tool outputs a list of variables and the reason for flagging as PII risk. This can then be reviewed with context to determine level of risk.

Please note the tool is not gauranteed to catch every risk but can catch more than during manual checks due to its ability to search every row, making it a more thorough, reliable and efficient method of carrying out PII checks.
